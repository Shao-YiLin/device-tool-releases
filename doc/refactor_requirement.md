## 1. 整体业务需求
### 1.1 底层通信库重构
将原有C私有通信协议完整翻译成Python，协议帧、校验、指令ID、交互时序1:1对齐原始工程；同时支持 BLE蓝牙、USB 双通道。
USB细分三类场景：设备直连、单通道接收器、多通道多设备接收器。

### 1.2 上位机功能
基于新Python通信库实现全套工具，功能清单：
1. 设备扫描、连接、断开；区分BLE/USB两种扫描入口
2. 多设备统一管理框架
   - 公共基础属性 + 公共基础功能（全设备通用）
   - 鼠标/键盘差异化特色功能隔离
3. 设备基础信息：ProductNo、设备名称、Mac地址
4. 全设备通用能力：录音、固件OTA升级
5. 鼠标专属能力：获取/设置CPI、获取/设置回报率

### 1.3 参考工程说明（src_archive）
1. mouseTool：原有C USB上位机交互流程参考
2. windows：C语言USB底层收发、协议封装核心参考
3. T8_light：键盘设备特有业务逻辑参考
4. AM50：鼠标CPI、回报率等专属指令参考
5. 马道设备通信协议.docx：完整协议说明文档（命令码、属性键、payload 格式）

## 2. 强制代码分层规范（AI生成必须遵守）
1. `new_project/comm_lib`：通信底层，BLE/USB实现统一抽象基类，上层不感知底层硬件
2. `new_project/device_model`：设备模型基类+鼠标/键盘子类，继承实现差异化功能
3. `new_project/device_mgr`：扫描、连接、多设备池管理
4. `new_project/mousetool`：上层业务入口，组装通信与设备模型
5. 通信协议解析独立在 `comm_lib/protocol`，与硬件通道解耦
